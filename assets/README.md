# 本地短视频素材

8 个无声 MP4 文件由本项目的 make_clips.py 原创生成，不含外部下载画面、字幕、类别名称或音轨。每段 3 秒，240×360，24 fps，H.264 / yuv420p，可离线使用。

- sport-0～3：运动人物与运动中的球。
- scenery-0～3：山景、河面、树木与飞鸟。

本版采用动画短片，不是真人实拍。类别与道路危险有无均衡分配；不声称已严格匹配两类视频的运动量或视觉显著性。正式收数前应试运行确认难度和播放兼容性。后续替换实拍素材时必须记录来源、许可、版本，并重新冻结收数前设计。

网页运行不需要 Python。仅重新生成素材需要 Pillow、numpy、imageio、imageio-ffmpeg；命令：python make_clips.py。
